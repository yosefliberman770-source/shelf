# Dictionnaire topographique de la France (DicoTopo)

- **Official source:** Comité des travaux historiques et scientifiques (CTHS) and École nationale des chartes; XML from github.com/chartes/dico-topo (commit in original/COMMIT). Commune positions: Wikidata items with an INSEE code (QLever, query in original/insee-coords.rq).
- **Dataset page:** https://dicotopo.cths.fr/
- **Version / date:** 53 départements (XML), 2026-09-30.
- **Licence:** Creative Commons BY-NC-ND 3.0 FR (stated in each XML file and the repository README). — https://creativecommons.org/licenses/by-nc-nd/3.0/fr/ (see LICENSE.md)
- **Geographic coverage:** The 53 French départements with a published dictionary.
- **Historical date range:** Old name forms from the early Middle Ages onwards, each with its date and source.
- **Download date:** 2026-09-30
- **Total size:** 303.2 MB in 53 files

## What it contains

Place articles: headword, type, commune (INSEE code), dated old forms with references.

## Processed into Shelf

22,366 communes (first attestation = earliest dated form, all dated forms kept as historical names) and 6,774 castles, churches and religious houses located by commune (approximate) → private data pack.
