# Overview
This repository contains a FAIR-compliant research dataset documenting historical place names (toponyms) in Western Bohemia (present-day Plzeň and Karlovy Vary Regions, Czech Republic) attested in written sources up to AD 1500.
The dataset integrates historical, linguistic and spatial information into a structured tabular format suitable for quantitative analyses, historical linguistics, onomastics, medieval settlement studies, historical geography and GIS-based research.
The published dataset represents a scholarly enriched derivative dataset. While the historical attestations originate from published academic sources, additional linguistic interpretation, morphological classification, cross-regional comparison and spatial georeferencing were produced within the research project.

# Dataset Structure
Each row represents one historical place-name record.
The dataset includes information on:
- unique identifier
- modern place name
- alternative or secondary place name
- settlement type
- administrative affiliation
- earliest written attestations
- reconstructed historical forms
- lexical base
- etymology
- morphological class
- derivational classification
- Slavic/German linguistic affiliation
- analogous place names in northeastern Bavaria
- assessment of analogy
- notes
- latitude
- longitude

Detailed descriptions of every variable are available in:
**Data_Dictionary.xlsx**
Complete methodological documentation is provided in:
**CODEBOOK.pdf**
